# meetyomo.in — the marketing site for Yomo

Yomo is a chat-first AI money app for Indian Gen Z that syncs Gmail, Zerodha and INDmoney read-only and answers money questions in chat with Roast/Pro/Zen personas. This repo is the pure-static marketing site (no build step) — five plain HTML pages (`index.html`, `pricing.html`, `security.html`, `about.html`) styled with Tailwind via CDN using Plus Jakarta Sans and the Yomo design tokens, a shared fixed header with mobile hamburger nav and a shared footer with a mailto-based waitlist capture plus the required non-adviser disclaimer. Hosting is GitHub Pages for the `Ashish5380/yomo-site` repo with the custom domain `meetyomo.in` (already recorded in the `CNAME` file); local icons live under `assets/`, favicon/apple-touch-icon links point at `assets/icon-64.png` and `assets/icon-180.png`, and the header/footer/mascot art uses local `assets/mascot.png`. To preview locally run `python3 -m http.server` and open `http://localhost:8000`. Pricing note: the Founding Member plan is Rs 99/month, forever, for the first 100 sign-ups (slot meter shown on index and pricing pages).
